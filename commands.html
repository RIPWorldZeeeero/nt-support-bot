Команды Support Net Tweaking Studio

Справочник slash-команд Discord-бота, основанный на исходном файле license_discord.py.

Команды вводятся в Discord через /. Для администраторских команд твой Discord ID должен быть указан в настройках бота. Параметры в примерах заменяй на настоящие значения.

Команды пользователей

/about

Информация о Support Net Tweaking Studio

Пример: /about
/license

Показать свои лицензии NT Launcher Premium

Пример: /license
/activate

Отправить запрос на офлайн-активацию

Пример: /activate request_code:NTREQ1...
/license_claim

Получить одобренный код активации

Пример: /license_claim request_id:123

Команды администраторов

/license_issue

Выдать лицензию пользователю

Пример: /license_issue owner:@пользователь note:Комментарий
/license_pending

Посмотреть ожидающие запросы

Пример: /license_pending
/license_approve

Одобрить запрос активации

Пример: /license_approve request_id:123
/license_deny

Отклонить запрос активации

Пример: /license_deny request_id:123
/license_info

Информация о лицензии

Пример: /license_info license_id:NTL-XXXXXXXXXXXX
/license_revoke

Запретить будущие активации

Пример: /license_revoke license_id:NTL-XXXXXXXXXXXX
/license_reset

Сбросить старые сетевые привязки

Пример: /license_reset license_id:NTL-XXXXXXXXXXXX

Примечание: отображение команд в Discord зависит от запущенной версии бота и синхронизации slash-команд. Пересылка сообщений настраивается отдельно и не имеет slash-команд в предоставленных исходниках.
